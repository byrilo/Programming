# Лабораторная работа №2
В окне "Choose enumaration" выберите одно из предложенных перечислений
После этого, в соседнем окне появятся все элементы этого перечисления 
Нажав на элемент перечесления, в текстовом поле справа будет отображен порядковый номер данного элемента
В текстбоксе снизу слева можно написать день недели, день недели должен определится, после этого выведется порядковый номер элемента в перечислении
В КомбоБоксе справа снизу можно выбрать любое время года, в зависимости от выбора будут происходить различные действия в программе, такие как изменение цвета или выведение МеседжБокса
